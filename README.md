# Dit-lokale-tomme-k-kken-
Dit Lokale Tomme Køkken hjælper unge med at spise sundere og mindske madspild. Brugeren indtaster ingredienserne derhjemme, og appen foreslår nemme og billige opskrifter. Løsningen gør det lettere at vælge hjemmelavet mad frem for fastfood og udnytter råvarer, der ellers ville blive smidt ud.
